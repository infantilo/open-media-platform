# Audit 2026-10-23 (nur gelesen, nicht gegengeprüft)

Gesamteindruck: guter POC im abgeschotteten Labornetz, nicht produktionsreif.
Belege (Datei:Zeile) stammen aus dem Audit-Agenten; vor der Umsetzung je Punkt gegen den Code prüfen.

## Stark
- Orchestrator-Login (bcrypt, Sitzungszähler, Audit-Log, Funktionsrechte), signierte Updates
- Instanz-Wiederaufnahme nach Neustart
- NMOS-Konformitätstests, govulncheck, cargo audit, CodeQL in der CI
- A/V-Offset ~56 ms von omp-source erledigt (Messartefakt, Ursache behoben)

## Blocker
1. Node-HTTP-API ohne Anmeldung, 0.0.0.0, CORS `*` (`nodes/omp-node-sdk/src/node.rs:708`, `server.rs:174-195`)
2. Host-Agent führt jedes NATS-Kommando ungeprüft aus; NATS ohne Auth/TLS; LaunchSecret im Klartext (`host-agent/main.go:312-330`, `commands.go:125`)
3. ffmpeg-Jobs: Path Traversal (`../`) und lokal keine Argumentprüfung (`host-agent/internal/jobs/jobs.go:140-174`, `orchestrator/internal/jobrun/local.go:20-40`) — Rechteausweitung bis Admin-Token-Fälschung
4. Produktions-Deployment = Dev-Stack: Patroni x3 auf einem Host, ohne Volume, Dev-Passwörter (`start-omp.sh:117`, `Makefile:248-280`)
5. Zwei-Knoten-Raft: Failover/Scheduler stehen bei Ausfall eines Knotens; Infrastruktur komplett auf .60

## Hoch
- H1 Registry offen; Stream-Proxy ruft Node-gelieferte URL auf (SSRF, `proxy.go:177-193`); Node-JS im Orchestrator-Origin, Token in localStorage
- H2 Bootstrap-Modus: ohne Nutzer alles offen (`auth_middleware.go:198-205`)
- H3 Tokens gelöschter/neu angelegter Nutzer bleiben gültig (`auth/service.go:193-212`)
- H4 Failover nur per Telemetrie-Timeout (20 s), kein Fencing, Split-Brain möglich (`workflows/failover.go:45`)
- H5 Instanz-Migration: erst Stop, dann Start, kein Rücksprung, keine MXL-Prüfung (`instancemigrate/service.go:146-175`)
- H6 Make-before-break nur Viewer/Bildmischer; Tonmischer nicht weich; MXL host-lokal
- H7 Rechteprüfung = DB-Abfrage pro Aktion, kein Cache (`authz/store.go:165-171`)
- H8 HTTP-Server ohne Timeouts; Node-Server single-threaded, ohne Body-Limit (`main.go:1100`, `server.rs:168-179`)
- H9 Rust-Panics/vergiftete Mutexe können Zombie-Nodes erzeugen
- H10 JWT-Secret pro Orchestrator lokal (`config.go:298`)
