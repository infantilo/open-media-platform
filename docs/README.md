# Dokumentation

Im Hauptordner liegen die zentralen Dokumente und alles, was von Code, Tests oder Skripten
per Pfad gelesen wird.

| Ort | Inhalt |
|---|---|
| `BENUTZERHANDBUCH.md`, `HANDBUCH.md` | Bedienung und Betrieb |
| `INSTALLATION.md`, `betrieb/` | Installation, Offline-Paket, Cloud |
| `FEHLERCODES.md` | Fehlercodes (wird per `go run ./cmd/errcodedoc` erzeugt, nicht von Hand ändern) |
| `END-GOAL-FEATURES.md`, `decisions.md` | Zielbild und Entscheidungsprotokoll |
| `funktionen/` | Funktionsbeschreibungen (Playout-Automation, Untertitel-ASR, Gebärdensprache) |
| `entwuerfe/` | Entwürfe und Pläne (`ENTWURF-*`, Radio-Plan, Ingest-Plan) |
| `contracts/` | Verträge für Nodes und Gateways (`CONTRACT-*`) |
| `entwicklung/` | Node-Tutorial, Module schreiben |
| `berichte/` | Abschluss-, Audit- und Konformitätsberichte |
| `ebu-diagrams/` | Architekturgrafiken und die EBU-Präsentation |
| `screenshots/`, `hero.png` | Bilder |
| `examples/`, `midi/`, `bcp-007-03/`, `descriptor-v0.schema.json` | Beispiele, Prüfwerte und Schemas (von Tests eingebunden, Pfade nicht ändern) |
