# Sicherheit / Security

**Sicherheitslücken bitte nicht als öffentliches Issue melden.** Nutze stattdessen die private Meldung:
<https://github.com/infantilo/open-media-platform/security/advisories/new>

Bitte angeben: betroffene Version, Beschreibung, Schritte zum Nachstellen, mögliche Auswirkung. Keine Zugangsdaten mitsenden.
Die Meldung wird vertraulich behandelt und erst nach einer Korrektur veröffentlicht.

Das Projekt ist ein Proof of Concept ohne formale Sicherheitszertifizierung. Unterstützt wird jeweils der aktuelle Release.

Please do not report vulnerabilities in public issues. Use the private advisory link above.
